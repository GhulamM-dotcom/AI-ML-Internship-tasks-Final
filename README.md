# 🧠 Task 1 – News Topic Classifier (BERT)

### 📌 Objective

Classify news headlines into categories using a transformer-based NLP model.

### 📂 Dataset

AG News Dataset (4 categories: World, Sports, Business, Technology)

### ⚙️ Tools

Hugging Face Transformers, PyTorch, Scikit-learn

### 🔑 Key Steps

* Text preprocessing
* Tokenization using BERT tokenizer
* Fine-tuning `bert-base-uncased`
* Training using Hugging Face Trainer API
* Evaluation using Accuracy & F1-score

### 📊 Results

* High classification accuracy achieved
* Strong generalization on unseen data

### 🚀 Deployment

* Interactive app using Streamlit / Gradio
* Real-time news classification
